# Restrict gold `from-reviews` article ids to the project

`POST /projects/{id}/gold/from-reviews` passed `payload.article_ids` straight to
`latest_reviews()`, which filters only on `article_id IN (...)` and the search (NULL
`search_id` on the initial search). A member of project A could pass an article id from
project B carrying a legacy annotation and freeze B's reviewer decision into A's gold standard.

- Explicit ids are checked against `Article.project_id`; any id outside the project is rejected
  with 422 `article not in this project`, like the manual gold POST.
- Test: a foreign article with a legacy (`search_id` NULL) annotation is rejected and no gold
  entry is created.

Tested: `ruff check`, `ruff format --check`, `pytest tests/test_gold_api.py tests/test_searches.py` (25 passed); the new test fails on `main`.
