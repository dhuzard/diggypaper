# Preserve human evidence in RO-Crate article exports

`articles/<key>/metadata.json` exported each human annotation as `answers` + `notes` only: no
annotation id or date, the reviewer's `evidence_quotes` were dropped, and nothing identified
the reviewer, so two reviews of one article could not be told apart or traced back.

- Each `human` entry now carries `annotation_id`, `created_at`, `evidence_quotes` (null if
  absent) and `reviewer_ref`, a project-scoped pseudonym (`reviewer-<sha256>`) derived from the
  same salted digest kept as `annotator_hash` on account deletion: same person → same reference
  within a project, unrelated references across projects, null when no identity remains. No name
  or e-mail is added to the JSON.
- README of the crate documents these fields and that quotes are not a source verification.
- Crate import ignores the extra fields (round-trip test unchanged and still passing).

Tested: `ruff check`, `ruff format --check`, `pytest tests/test_crate_import.py tests/test_team_export.py` (18 passed); the new test fails on `main`.
