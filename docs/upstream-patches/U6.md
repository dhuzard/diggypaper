# Make the PubMed window test independent of today's date

`tests/test_pubmed.py::test_fetch_all_pmids_splits_queries_over_the_ncbi_window` fails on
some calendar days (`AssertionError: '1035' == '1039'`). Its fake `fetch_pmids` returned each
date window's ids in ascending order, so `got[0]` was the oldest id of the most recent leaf
window, and leaf window widths depend on `date.today()` (bisection up to today + 366 days).

- Test only: the fake now returns newest first within a window, as esearch does by default,
  so the "most recent first" assertions no longer depend on how the windows fall.
- No implementation change.

Tested: `ruff check`, `ruff format --check`, `pytest tests/test_pubmed.py` (23 passed; 1 failed on `main` on 2026-10-27).
