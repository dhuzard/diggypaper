# SEIP pure scoring foundation v0.1

This is an isolated engineering contract for [issue #7](https://github.com/dhuzard/diggypaper/issues/7), implementing arithmetic from the draft qualification protocol. It contains no real paper dataset, independent reference annotations, scientific results or qualification decision. `app/seip_scoring.py` uses only the Python standard library and does not change existing `metrics.score`, benchmark execution, APIs or UI. The protocol draft and this implementation still require independent review.

## Entry point and retained artifacts

`score_pilot(manifest, references, outputs, evidence=None)` returns a JSON-serializable dictionary with version `seip-scoring/v0.1`. Its typed inputs are Python dataclasses. This foundation deliberately has no database, network, model invocation, JSON ingestion adapter or artifact replay implementation. It never modifies caller data. Unknown contract versions, duplicate paper IDs, unknown fields/papers, contradictory typed records and invalid scoring configuration fail closed with `ValueError`.

`Manifest` identifies the protocol, approved codebook, frozen model configuration, archived attempt manifest and reference set. A lowercase 64-character `attempt_manifest_sha256` is required and echoed in results alongside its immutable artifact ID. These are **caller-supplied identities and digest, unverified by this scorer, not proof of qualification**. Callers must retain the referenced documents and validate the archived manifest and its hash before empirical scoring. The external scientific manifest must preserve aliases/duplicate-study checks, selection rule/reasons, exclusions, source/license availability, source and exact effective-input SHA-256 hashes, retrieval details, invocation attempts/errors, predeclared retry selection, prompts/model/decoding/software identities, frozen reference provenance and the adjudication trail. This scorer checks the digest's format but does not read, hash, create or authenticate those artifacts. Missing reference records remain visible even when a reference-set ID is supplied. Issue #7 remains open: artifact ingestion/validation, independent review, replay and empirical qualification are pending.

Each `PaperAttempt` represents an attempted paper, including a failed call. It records a paper ID, effective-source stratum, development/held-out split, eligibility and example flag. Include unsuccessful attempts in the manifest; deriving it from successful predictions would defeat the denominator rule. Retries must be archived and resolved by an externally frozen choice rule before supplying one selected `PaperOutput` per paper. There is no automatic retry selection. Development, examples and ineligible papers are counted as exclusions, with overlapping reasons allowed, and cannot contribute to estimates. Eligible held-out papers remain in per-paper results and all bootstrap samples even when they lack outputs, reference fields, quotations or links. Unattempted enrollment/completion tracking belongs in the external manifest.

`FieldSpec` declares categorical, numeric or binary items before scoring. Housing/intervention subitems and individual methodological checklist items must be separate predeclared keys when the approved codebook requires this. No field names or semantic classes are inferred from text.

## Missingness, reporting status and values

`ReferenceField` has one of `reported`, `not_reported`, `not_accessible`, `not_applicable`, `unclear`. Only the first two enter eligible field coverage and reporting-status correctness. A `reported` reference must have at least one adjudicated observation. The other states cannot carry observations. Missing references count as `missing_reference`, not as `not_reported`, false negatives or true negatives; proposed values on these or excluded reference states are counted as `unscored_proposals`. A completely absent paper reference also increments `papers_without_reference`.

An omitted output means `missing_call`. `PaperOutput` also preserves `invalid_json`, `invalid_schema`, `error` or `valid`. Failed calls carry no parsed fields in this arithmetic interface; their raw bytes/errors belong in the invocation archive. A valid output can omit a field or supply `PredictedField("invalid")`. Every usable predicted field requires an explicit immutable `answer_revision` identity. Each missing/invalid eligible field contributes an attempted failure and a separate reason count. Even when the reference is `not_reported`, absence is never a correct negative. The reporting confusion keys explicitly distinguish missing output from each supplied reporting status.

A valid explicit reporting status counts as covered, including a valid explicit `reported` status whose observation list is empty; absent values still become unmatched references. Reporting-status correctness requires exact agreement with adjudicated `reported` or `not_reported`. Correct status does not imply correct value. Other explicit predicted statuses may be covered but are incorrect against eligible reference statuses.

`Observation` contains a typed value, explicit scope dimensions and an optional numeric unit. Matching is exact over value **and type**, unit and scope. Scope dimension order is ignored; spelling, case, whitespace, synonyms, values and units are never normalized by this scorer. Numeric integers and codebook-defined range strings are permitted; `10` and `"10"` differ, and booleans cannot become numeric counts. Every numeric value requires an explicit unit. Domain-approved semantic equivalences must be resolved into separately retained canonical labels under the frozen codebook before scoring; token overlap is never used.

Matching uses multiset intersection. Each reference observation can match at most one proposed observation. Unmatched predictions, including duplicates and proposals on a `not_reported` field, are FP; unmatched reported reference observations are FN. Precision, recall and direct `2TP/(2TP+FP+FN)` F1 accompany raw TP/FP/FN. Binary observation metrics describe exact scoped boolean observations; `binary_positive_*` and `binary_negative_*` separately report the two predeclared boolean classes with TP/FP/FN/TN. Each binary scope has at most one observation. A missing eligible positive is positive-class FN. A missing eligible negative is negative-class FN plus missing-output count, and **never positive-class TN**. An extra scoped proposal is FP for the class it proposes. Non-binary TN is structurally unused (zero).

Numeric diagnostics count unmatched predictions that share an exact value/type with a reference but have a different unit/scope, and unmatched predictions sharing unit/scope but differing in value/type. These diagnostic counts are nonexclusive in multi-observation cases; they do not change the primary one-to-one TP/FP/FN counts or imply a tolerance.

## Evidence is supplied and measured separately

`EvidenceJudgments` supplies a complete inventory of proposed quotation records and links for a paper. An explicitly supplied empty inventory means zero proposed records. An omitted inventory means unavailable evidence accounting, counted in `papers_without_evidence_judgments` and `eligible_answers_evidence_unavailable`; it is not silently called zero-link output. Missing evidence accounting must be resolved before an empirical evidence claim.

`QuoteJudgment` keeps independent existence and attribution outcomes, plus producer claims and their independent checks. It does not run a verifier or infer support. Nonempty malformed quotations remain in the nonempty verbatim denominator. Empty quotation records have `existence="empty", emitted_nonempty=False`; they still count as proposed evidence records. Existence outcomes include exact, normalized-only, absent, malformed, empty, source-unavailable and not-assessed. Attribution has correct, incorrect, ambiguous, unavailable and not-assessed outcomes. Repeated occurrences are one existence event per quotation record, with ambiguous locations retained as ambiguous attribution; separate emitted duplicate records remain separate proposals.

Verbatim rate uses exact / emitted nonempty quotations. Attribution uses correct / all proposed evidence records. The unverifiable numerator counts each quotation **once** if it is absent, empty, malformed, source-unavailable or has ambiguous attribution; its denominator is all proposed quotation records, including empty records. Normalized-only and unassessed counts are separately visible. Missing evidence inventories have no invented quotation records or denominators.

False existence verification is measured separately for exact and normalized source-present claims. The primary assessed-only rate is independently failed stated-rule checks / independently assessed claims; unknown checks cannot dilute it. Assessment coverage is assessed / all labelled claims. The protocol's all-labelled arithmetic is retained under explicit `*_all_labelled_lower_bound` names: known failures / all labelled claims. This is only a lower bound when checks are missing, not a clean error estimate. Known-negative challenge false acceptance counts producer source-present claims / known-negative challenge records. False unique attribution similarly publishes an assessed-only primary rate, assessment coverage and an all-labelled lower bound, excluding ambiguous locations and counting those exclusions separately. Unassessed exact, normalized and uniqueness checks remain visible; all-unassessed primary rates are NA. Producers' claims and independent test outcomes must both be retained, even when they disagree.

`LinkJudgment` identifies a proposed link, field, evidence record, immutable answer revision and exact answer scope, and separates scoped link correctness from scientific support. Invalid, dangling, stale-revision or wrong-scope proposals remain in link denominators with `incorrect` or `not_assessed` correctness. A record asserted `correct` must reference a supplied quotation and the current usable answer revision/scope; this structural check does not adjudicate scientific scope equivalence or support. Eligible scoped answers with zero proposed links and those with at least one correct link are separately counted, only calling an answer zero-link when its inventory is supplied. Linking another revision/scope cannot satisfy the current answer's link coverage. Here an eligible answer is a covered eligible predicted field revision at one explicitly proposed observation scope, grouping observations with identical scope; a pure reporting-status answer has empty scope. Field coverage itself remains at the paper-field level.

Scientific-support error uses (`contradicts` + `insufficient`) / all final independently adjudicated links. Final `unclear` judgments belong in that primary denominator and assessment coverage; `not_assessed` does not. Raw supports, contradicts, insufficient, unclear and unassessed counts must accompany the rate. A separate `scientific_support_error_determinate_only` sensitivity rate excludes unclear judgments and `support_determinate_coverage` exposes its coverage. Neither rate is a claim of known-support accuracy among unresolved links. Challenge eligibility is supplied by humans: negation/conflict error counts adjudicated eligible challenge links presented as supporting whose support is contradicts/insufficient, divided by all adjudicated eligible challenge links. No detector or sensitivity claim is implemented.

## Results and uncertainty

Every metric publishes numerator, denominator and value. A zero denominator is Python `None` (JSON `null`), to be rendered as `NA`, never zero or perfect. Results expose overall, source-stratum, field and per-paper arithmetic; field summaries describe extraction, while evidence summaries pool quotations/links within paper and stratum. Unsupported field-level evidence metrics are NA. All results retain `qualification="not_assessed_by_scorer"`.

The 95% paper-cluster percentile bootstrap defaults to 2,000 resamples with the manifest seed. Paper IDs are sorted before sampling; manifest order cannot change the result. Each draw samples the same number of entire eligible held-out papers with replacement and carries all of each paper's field/quotation/link counts. No-output, missing-gold and zero-link papers participate. Intervals are reported overall, per field and per stratum, with the paper IDs, method, seed, resample count, defined and undefined replicates. A zero relevant denominator makes that replicate undefined. Bounds use linear-interpolated 2.5% and 97.5% quantiles of **defined** replicates only, explicitly conditional on being defined; all-undefined intervals are NA. The undefined count must be displayed, not silently omitted. Small purposive strata do not support population-representative accuracy claims.

This module does not define a binary paper-level success outcome, so it does not manufacture a Wilson interval for one. Pre-adjudication agreement/kappa, raw source replay, artifact exports, invocation ingestion and empirical eligibility gates remain separate work. No existing historical gold is relabelled independent or adjudicated.

## Hand-calculated synthetic checks

The fixtures in `backend/tests/test_seip_scoring.py` are engineering examples, not real paper observations:

- Seven held-out eligible `not_reported` fields, with one explicit correct status and six distinct missing/invalid failure types: coverage and reporting correctness are both 1/7. Development/examples do not enter the seven.
- Two scoped reference observations, one exact match, duplicate/incorrect-scope proposals and an invented observation on a `not_reported` field: TP=1, FP=3, FN=1, precision=1/4, recall=1/2, F1=1/3.
- One positive and nine negative binary references; nine explicit negative predictions and one absent negative output: positive TP=0, FP=0, FN=1, TN=8; negative TP=8, FP=1, FN=1, TN=0. The absent negative does not increase TN.
- A reference numeric count 10 animals in arm A, with proposals 10 cages, 11 animals and string `"10"` animals: TP=0, FP=3, FN=1, one unit/scope diagnostic and two value/type diagnostics.
- Two exact quotations among five nonempty emissions: verbatim 2/5, while independent attribution is 2/6 and link correctness 2/5. Two support errors among four adjudicated links, including one unclear, yield primary error 2/4; unassessed links remain outside that denominator.
- A three-paper bootstrap with one quoted-output paper and two no-output papers has undefined quote-rate replicates exactly when the quoted paper is not sampled. Tests reconstruct the fixed-seed draws independently and verify unchanged counts, missing clusters, NA intervals and input purity.

## Judgments requiring qualified humans

Qualified domain reviewers must approve the field codebook, searched-section/access policy, synonyms/canonicalization, value/unit/scope interpretation, one-to-one ambiguity policy, challenge definitions and support/adjudication procedure **before** held-out evaluation. They must determine reporting states, extract and scope reference values/passages, distinguish animals from other units/populations, resolve contradictory context and approve any semantic equivalence. Two reviewers must create independent blinded Stage A references; a separate qualified adjudicator must resolve disagreements while preserving original labels, identities/pseudonyms, timestamps, procedure, source versions and conflicts. Agents and these synthetic fixtures cannot provide independent scientific reference data.

After Stage A is frozen, qualified humans must independently assess the exact answer revision, passage and context for scoped linkage and scientific support, including negation, population/cohort, intervention timing, unit of analysis and conflict. They must designate challenge eligibility, resolve Stage B disagreements with a separate adjudicator, and retain unclear/unassessed outcomes. Authenticity checks may be deterministic software checks when their frozen source/input and match rules replay; software existence is never a human support judgment. Finally, qualified humans must review observed failure modes, source-rights/access constraints, limitations and the bounded continue/stop decision. Until these artifacts and judgments exist, empirical qualification remains pending.
